# 💻 Lightweight Python IDE (Tkinter)

A minimal desktop Python Integrated Development Environment (IDE) built using **Python's Tkinter** GUI toolkit (`ScrolledText`, file dialogs, menu bars) and `subprocess` for executing scripts directly from the editor.

---

## 📂 Repository Structure

- `test_file.py`: Main Tkinter IDE application script.
- `README.md`: Project documentation.

---

## ✨ Features

- **Scrollable Code Editor**: Multi-line code editing area powered by `tkinter.scrolledtext.ScrolledText`.
- **File Management & Keyboard Shortcuts**:
  - **Open File** (`Ctrl+O`)
  - **Save / Save As** (`Ctrl+S`)
- **Integrated Code Execution**: Runs the active Python script via `subprocess` and displays standard output and tracebacks in a dedicated output pane.

---

## 🚀 Getting Started

```bash
git clone https://github.com/sparsh0106/Python-IDE.git
cd Python-IDE
python test_file.py
```
*(Uses only Python standard library modules—no external packages required.)*
